THE WHITE PALM SUPPORTING SITE - GITHUB

Target URL assumed in this package:
https://thewhitepalm.github.io/

Main / Tier 0 site:
https://thewhitepalm.pages.dev/

DEPLOY
1. Upload the CONTENTS of this folder so index.html is at the web root.
2. Open /sitemap.xml and /robots.txt after deployment.
3. Add the property to Google Search Console and submit sitemap.xml.
4. Request indexing for the homepage only.

IMPORTANT
- If the final free subdomain is different, replace EVERY occurrence of:
  https://thewhitepalm.github.io/
  in index.html, sitemap.xml, robots.txt and 404.html BEFORE indexing.
- Do not point canonical to the main site; this page is intentionally unique and should be indexed on its own.
- Keep the link to https://thewhitepalm.pages.dev/ as the contextual reference to the official villa site.
- GitHub Pages note: https://thewhitepalm.github.io/ works only if the GitHub user/organization name is exactly "thewhitepalm". Otherwise use https://USERNAME.github.io/ (or /REPO/) and update the files above.
